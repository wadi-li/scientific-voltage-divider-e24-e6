# Делитель напряжения E24 / E6 — научный калькулятор

Автономный HTML-калькулятор резистивного делителя (и делителя обратной связи Vfb) с подбором пар **E24**, конденсатором **E6**, worst-case анализом по допускам, ТКС и ТКЕ и графиками АЧХ.

- **Веб-версия (GitHub Pages):** https://wadi-li.github.io/scientific-voltage-divider-e24-e6/
- **Android APK:** [apk/voltage-divider-e24-e6-1.0.apk](apk/voltage-divider-e24-e6-1.0.apk) · также в [Releases](https://github.com/wadi-li/scientific-voltage-divider-e24-e6/releases)

Файл `index.html` полностью автономный: без CDN, шрифтов из интернета и внешних библиотек; графики рисуются встроенным Canvas-кодом. Можно открыть локально двойным щелчком.

## Возможности

- Режимы: **Vin → Vout** и **Vout (Vfb) → Vin**; единицы V / mV, шаг 0,05 V / 50 mV.
- Точность известного напряжения (Vin или Vfb): **±%** или прямой ввод **min / nom / max** из datasheet.
- Резисторы E24, выбор декад ряда, цель R1+R2, допуски R1/R2 (0,05…5 %), ТКС 15/50/75/100/200/500 ppm/°C.
- Отключаемая нагрузка Rн ∥ R2.
- Конденсатор E6: C ∥ R1, C ∥ R2, C ∥ Rн; ввод Fc (кГц) → расчёт C, или выбор C → Fc; условие |Xc| = R выбранного резистора или Req; допуск C; диэлектрик C0G / X7R с ТКЕ.
- Таблица worst-case по температурам −55, −40, −20, 0, +25, +55, +85 °C.
- Графики: семейство АЧХ по температурам; АЧХ worst-case с заливкой при выбранной T; искомое напряжение от температуры (относительная шкала, заливка, чекбоксы: допуски, ТКС, ТКЕ, Vin/Vfb; DC или на частоте анализа).
- Таблица пар E24 (клик по строке — выбор пары для графиков), экспорт CSV (`;`, UTF-8 BOM).
- Компоновка в один экран Full HD (1920×1080); вертикальная одноколоночная компоновка для телефона; светлая тема по умолчанию и переключатель тёмной.

## Модель и ограничения

- `Vout = Vin · R↓ / (R1 + R↓)`, `R↓ = R2 ∥ Rн`; в режиме обратной связи `Vin = Vfb · (R1 + R↓) / R↓`.
- `R(T) = R₂₅ · (1 + ТКС · 10⁻⁶ · (T − 25))`. Номинальная кривая — ТКС обоих резисторов со знаком «+»; границы — независимые ± допуски и ± ТКС каждого плеча и крайние Vin/Vfb (перебор углов).
- C0G: номинал без ухода, границы ±30 ppm/°C. X7R — инженерная оценка: номинал `C·(1 − k·|T−25|)`, границы `C·(1 ± k·|T−25|)`; DC bias, старение и частотная зависимость MLCC не учитываются.
- Не учитываются ток входа FB, утечки, саморазогрев резисторов, шум опорника.

## Android

Оболочка WebView (Android 7.0+, без разрешений, работает офлайн). Исходники в `android/`; сборка без Gradle: `aapt2 → javac → d8 → zipalign → apksigner` (см. `android/build.sh`, нужны build-tools 34, platform android-34, JDK 17 и собственный keystore: `KS=… KSP=… ./android/build.sh`).
